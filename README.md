# Guilherme Mazzolini — Portfolio

Personal portfolio of **Guilherme Mazzolini**, a Berlin-based full-stack developer.

Live site highlights client work, personal products, and a few motion experiments built with React, Next.js, and GSAP.

## Tech stack

- **Front-end:** React, Next.js, TypeScript, JavaScript, Tailwind CSS  
- **Back-end & data:** Node.js, Express, REST APIs, MongoDB, Stripe, AWS / Serverless  
- **Motion & deploy:** GSAP, OAuth, Vercel, Netlify  
- **Tools:** Git, Cursor / AI-assisted development  

This site itself is built with **Next.js 15**, **React 19**, and **styled-components**.

## Getting started

Requires **Node.js 18.18+** (20 recommended).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production build
npm start       # serve the build
```

## Project structure

```text
src/
  components/   # Hero, Projects, Technologies, Timeline, Header, Footer
  constants/    # Project data and timeline entries
  layout/       # Page shell
  pages/        # Next.js pages router
  styles/       # Global styles and shared UI
  themes/       # Design tokens
public/
  images/       # Project screenshots
  cv.pdf        # Downloadable CV
```
